Este repositório reúne os trabalhos práticos desenvolvidos durante os estudos da disciplina de **Estrutura de Dados**, utilizando principalmente a linguagem **C**.

Os projetos abordam conceitos fundamentais da programação, começando pelo uso de **funções e ponteiros**, passando por **alocação dinâmica de memória** e **listas dinâmicas**, até chegar ao estudo e à implementação de estruturas de dados mais complexas.

## 📂 Trabalhos

### 1. 🔧 Trabalho 1 — Prático: Funções e Ponteiros em C

Introdução ao uso de funções e manipulação de memória através de ponteiros na linguagem C.

Principais conceitos abordados:

* Funções;
* Ponteiros;
* Passagem de parâmetros;
* Manipulação de variáveis através de endereços de memória;
* Organização do código em C.

📁 `Trabalho 1: Prático Funções e Ponteiros em C`

---

### 2. 🧠 Trabalho 2 — Prático: Alocação Dinâmica

Estudo da alocação dinâmica de memória e do gerenciamento manual de memória utilizando recursos da linguagem C.

Principais conceitos abordados:

* `malloc()`;
* `calloc()`;
* `realloc()`;
* `free()`;
* Ponteiros;
* Gerenciamento dinâmico de memória.

📁 `Trabalho 2: Prático Alocação Dinâmica`

---

### 3. 🔗 Trabalho 3 — Trabalho Prático: Listas Dinâmicas

Implementação e estudo de estruturas de dados baseadas em listas com alocação dinâmica de memória.

Principais conceitos abordados:

* Estruturas (`struct`);
* Nós;
* Ponteiros;
* Listas encadeadas;
* Inserção de elementos;
* Remoção de elementos;
* Busca;
* Percurso de listas;
* Liberação de memória.

📁 `Trabalho 3: Trabalho Prático Listas Dinâmicas`

---

### 4. 🌳 Trabalho 4 — Estudo e Implementação de Estruturas de Dados

Estudo de estruturas de dados baseadas em árvores e outras estruturas hierárquicas.

Entre as estruturas estudadas estão:

* Árvore Binária de Busca (BST);
* Árvore AVL;
* Árvore Rubro-Negra;
* Árvore B;
* Trie;
* Heap Binário.

O trabalho apresenta conceitos relacionados à organização, inserção, busca, remoção e eficiência dessas estruturas.

📁 `Trabalho 4: Estudo e Implementação de Estruturas de Dados`

---

## 🚀 Como utilizar

Clone o repositório:

```bash
git clone https://github.com/ED-Trabalhos/Projetos-de-estrutura-de-dados.git
```

Entre no diretório:

```bash
cd Projetos-de-estrutura-de-dados
```

Escolha o trabalho que deseja estudar:

```bash
cd "Trabalho 1: Prático Funções e Ponteiros em C"
```

Para compilar um programa em C utilizando GCC:

```bash
gcc main.c -o programa
```

Execute o programa:

```bash
./programa
```

> O comando de compilação pode variar de acordo com os arquivos existentes em cada trabalho.

## 📖 Objetivo

O objetivo deste repositório é registrar e organizar os trabalhos realizados durante o aprendizado de **Estrutura de Dados**, permitindo acompanhar a evolução desde conceitos fundamentais da linguagem C até a implementação de estruturas mais avançadas.

Os projetos também servem como material de consulta e prática para conceitos como:

* Ponteiros;
* Manipulação de memória;
* Alocação dinâmica;
* Tipos abstratos de dados;
* Listas;
* Árvores;
* Algoritmos de busca;
* Organização e modularização de programas em C.
